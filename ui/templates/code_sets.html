Code sets

Each coded field of the canonical model {{ (release.version if release else model.version) }} holds a canonical code. Here every value the source actually uses is mapped to one, once for this migration. XODUS suggests a code when the value is the code, one of its known spellings or its description; a person approves every mapping. The approved map is data the generated procedures read, so a new source value is a reviewed data change, not new SQL.
