Publish artifacts

Publishing the artifacts: the stored ADF package goes to the linked GitHub repository as one commit. The owner of the data factory links that repository in Data Factory and takes the artifacts from there, so no Azure sign-in is needed from this platform to hand them over.

Data plane
This stage. Follows 07 Transformation SQL, which builds the ADF package. Publishing adds a commit to the configured branch only: it never force-pushes, deletes files or touches other branches. Pulling the published artifacts into Data Factory from this platform is the next piece of work and is not part of this stage yet.
