Target system setup

Platform-level and one time: the Platform Admin connects the target, lets the platform infer its model, reviews it and confirms it. Every migration then maps to this confirmed target; migration users see only the inferred model on the Target mapping page. The target's value for each canonical code is set under Target code values.
