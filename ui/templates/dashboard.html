NOT ACTIVE IN P0

1. Data-quality readiness

Group records by validation status: critical keys present, required fields complete, duplicate checks passed, and documented relationships resolvable.

Evidence: profile + validation results

2. AUM bands (if reliable)

Use agreed AUM ranges only when a trusted, dated AUM field and its currency/valuation date are available. Business owner defines the bands.

Evidence: validated AUM + valuation date

3. Source / custodian readiness

Separate cohorts only where source systems or custodians require materially different mapping, operational handling, or validation.

Evidence: source profile + owner confirmation

4. Relationship completeness

Prioritize records with documented Account–Client and Client–Household links; isolate unresolved or orphan relationships for remediation.

Evidence: documented keys + MCL checks

5. Complexity / exception load

Keep records with unusual registrations, unsupported formats, or high exception counts in a separately managed remediation cohort.

Evidence: exception counts + reviewed rules

6. Telemetry-driven readiness

Later, read ADLS processing telemetry and update cohort eligibility from measured completion, validation, and reconciliation status—not arbitrary wave numbers.

Evidence: ADLS telemetry (future phase)

Guardrail: do not assign waves until source data is profiled, definitions are approved, thresholds are documented, and cohort decisions are auditable.
