Hands the generated ADF artifacts to the data factory owner without an Azure sign-in. XODUS adds one commit with the stored package to this repository; the factory owner links the repository in Data Factory (Manage, Git configuration) and publishes from there. The token is read from a server environment variable and is never typed here. XODUS only adds commits to the branch below: no force push, no deletes, no other branches.
