Canonical model governance

Canonical Change Requests

When the migration needs something the canonical model does not provide, a Migration Analyst raises a change request. The Domain SME (canonical model owner) approves, rejects or defers it. Approved requests are the versioned backlog for the platform team; this screen does not edit the canonical model itself.
